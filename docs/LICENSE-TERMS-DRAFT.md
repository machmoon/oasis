# License terms: a draft for Pat to decide (NOT IN EFFECT)

Oasis sells "a license to import and ship" each program (the only term the registry states, in every 402). Buyers'
most repeated worry in tonight's research was unclear terms, and the judges flagged that the game pack's
LICENSE.txt admits there are none. Nothing below is live or shown to buyers. Pick an answer per question; then the
kit page, the 402 description, /llms.txt and the pack's LICENSE.txt can quote it.

The questions every comparable store answers, and how the big ones answer them (check the current pages before
relying on these; they are summaries, not quotes):

| Question | Splice Sounds (support.splice.com, "Splice Sounds licensing FAQ") | Sonniss GDC bundle (sonniss.com/gameaudiogdc) | Options for Oasis |
|---|---|---|---|
| Commercial use in a game, app or video? | Yes, royalty-free | Yes, royalty-free | Yes / Yes up to N units / No |
| Does the license end if you stop paying? | No, perpetual for what you downloaded | No, perpetual | Perpetual once the 14-day refund window closes / Subscription |
| Is credit required? | No | No | Not required / Required (the pack already has a suggested credit line) |
| Can the raw files be resold or shared as a sound library? | No | No | No / Yes |
| Can they sit in a public game repo? | (not addressed directly) | (not addressed directly) | Yes, as part of a game / No |
| Can they be used to train AI models? | (check) | No | No / Yes |
| What does a refund do? | n/a | n/a | Revokes the license (the code already does this) |

Oasis-specific points to settle:
- The live module URL carries the licence token (`?lic=`). Say whether shipping it in a public web game is allowed,
  or recommend the WAVs for public code.
- A license is per program: does it cover every knob setting and seed (the code allows it), and forks of it?
- A kit someone else paid for can be licensed again as your own copy; say that each buyer holds their own license.

Until this is decided, the honest line (already in LICENSE.txt) is: the registry states "license to import and
ship"; fuller terms are not published yet.
