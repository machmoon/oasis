# Reference projects (what Oasis must beat)

Facts only, as published. Judge each on what is described; do not invent strengths or weaknesses.

## R1. Polyfork — Build with Gemini XPRIZE, 1st place ($500,000), the current XPRIZE winner
(Full Devpost summary in polyfork-devpost.md.) Store of parametric low-poly 3D models sold as programs with knobs,
remixed in the browser before download; 583 models (now ~1,900), 5,774 knobs, kits that share one grid and palette
(513 of 583 in kits); ES modules from a CDN, GLB/FBX/USDZ; MCP server and REST API ("14,524 API and MCP calls from 29
keys"); Unity connector (open source); agent factory with an independent grader rejecting about two thirds;
54 paying customers and $4,428 first-month revenue; polished playful diorama visuals (isometric low-poly towns).

## R2. CrawlerPal — PayPal Dev Days 2025 hackathon, 1st place ($5,000)
An AI agent assistant that handles paywalls, built with PayPal APIs in an agentic integration. Judged after live
demos by a panel of three PayPal executives; praised for innovation combining AI agents with payments.

## R3. Codebusters — PayPal Dev Days 2025 hackathon, 2nd place ($3,000)
Modernised the PayPal integration for Shopware 6 (open-source e-commerce) from JS SDK v5 to the v6 beta: performance,
maintainability, alignment with PayPal's latest standards.

## R4. Rosen — PayPal Dev Days 2025 hackathon, 3rd place ($2,000)
Upgraded a global social trading app using PYUSD (PayPal USD stablecoin).

## R5. Countersign — agentic-payments hackathon winner (&hacks, William & Mary), now an open-core project
A payment firewall / control plane for AI agents that spend money: policy, sub-second freeze, signed audit ledger
across wallet backends (Coinbase, Turnkey, Openfort, a Lithic Visa card); push-notification approval cards
("the agent proposes, policy and people decide, and only the signer can pay"); MCP tools; ~432 ms on testnet;
1,600+ tests.
